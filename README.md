# Assignment 5. JavaScript Basics (DOM Manipulation & Events)

Student: Kamila Ahmadzada
Group: SE-2530

## Description
A multi-page website with JavaScript tasks on variables, DOM manipulation, events, a calculator and a to-do app.

## Live site
https://kamilaahmadzada.github.io/WebAssignment-5/

## Pages
- index.html: Part 1 (Task 0 First Script, Task 1 Variables & Operators)
- dom.html: Part 2 (Task 2 Changing Content, Task 3 Changing Styles, Task 4 Creating & Removing Elements)
- events.html: Part 3 (Task 5 Mouse Events, Task 6 Keyboard Events, Task 7 Calculator)
- todo.html: Part 4 (Task 8 To-Do App)

## How to run
Open the live site link, or open index.html in a browser (or use Live Server in VS Code). Open the console (F12) on the first page to see the output of Tasks 0 and 1.
